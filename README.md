# AIスマートオフィス・入退室管理ダッシュボード

**SECURE 模擬プロジェクト**

AIと映像解析を活用した、スマートオフィス向け入退室管理ダッシュボードのプロトタイプです。株式会社セキュアへの応募ポートフォリオとして、画面設計とフロントエンド実装をまとめています。

## プロジェクト名

AIスマートオフィス・入退室管理ダッシュボード（SECURE 模擬プロジェクト）

## 開発背景

AIとDXを活用し、オフィスのセキュリティ向上と日々の運用効率化を支援するプロトタイプとして開発しました。入退室状況やAIカメラの検知情報を一つの画面に集約し、状況を直感的に把握できるダッシュボードを目指しています。

## 主な機能

- 社内の残留人数や入館者数などの状況表示
- AIカメラの検知ログと認証結果の表示
- フロア内のカメラ配置イメージの表示
- 出勤・退勤登録と、日時付き操作履歴の追加
- 画面幅に応じたレイアウト調整

## AI協業経験

本プロジェクトでは、AIにコード作成を任せきりにするのではなく、OpenAI Codexエージェントと対話しながら、要件の整理、画面構成の検討、実装内容の調整を主導しました。生成された内容を確認し、意図に合うよう具体的な指示と修正を重ねることで、試行錯誤の時間を短縮し、開発の生産性を大きく高めることができました。

この経験を通じて、AIの提案を適切に評価し、人が目的と品質に責任を持って開発を進めることの重要性を学びました。

## 使用技術

- HTML5
- CSS3
- JavaScript
- OpenAI Codex Agent
- Git / GitHub

## 起動方法

リポジトリを取得後、`index.html` をブラウザーで開くと画面を確認できます。ビルドツールや追加の依存パッケージは使用していません。

## 留意事項

本リポジトリは応募用の画面デモを目的とした模擬プロジェクトです。表示される人数・検知ログはサンプルデータであり、実際のカメラや入退室管理システムとは連携していません。出退勤登録の履歴は画面上での動作確認用で、サーバーへの保存は行いません。
