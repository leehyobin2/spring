## 💻 3. 主な機能（コア・テクノロジー）

### ① リアルタイム・ステータ스パネル 📊
* 社内残留人数、不審者検知アラート、稼働中のAIカメラ台数などの主要DXデータを視覚的に集約。
* セキュア社のコーポレートカラーを意識した、信頼感のあるダークネイビー（#0A192F）主体のモダンなB2B UIデザイン。

### ② リアルタイムAIカメラ検知ログ（非同期シミュレーター） ⚡
* **JavaScriptの非同期タイマー機能（`setInterval`）**を活用し、実際のAIサーバーやカメラハードウェアが連동しているかのような「3〜5秒ごとのランダム・ログ生成シミュレーター」を独自設計。
* ログ生成時にローカル環境のシステム時間を超精度で計算し、`[HH:MM:SS]` 形式でリアルタイムにタイムスタンプを自動注入。

### ③ インタラクティブ操作履歴システム（出退勤ログ） 🔑
* ユーザーが「出勤登録」「退勤登録」ボタンをクリックすると、フロントエンド側でイベントを検知し、操作履歴（ログ）が画面最下部に動的なログデータとして追加される仕組みを実装。

## 🚀 5. 主体的な課題解決ストーリー（デバッグ経験）
開発の過程において、AIの提案に対して主体的に向き合い、技術的なトラブルを自力で解決しました。

1. **認証トークン（Token）競合およびGitHub連携エラーの解決**
   * ローカル環境における過去の認証情報（Invalid username or token）の競合に対し、VS Code内の内蔵ターミナルを駆使し、リモートURLの再設定（`set-url`）および強制プッシュ（`force push`）コマンドを自ら組み合わせて実行し、認証の競合問題を根本的に解決。
2. **Git環境変数の未認識トラブルの克服**
   * Windows環境におけるGitバイナリパスの未認識エラーに直面した際、システム構造を分析してプロセスをリフレッシュ（VS Codeの再起動およびターミナル初期化）し、ステージング（Staging）およびコミットのワークフローを完全に制御してデプロイに成功。
