## 💡 プロジェクトについて

SENTINELは、サービスの稼働状況や主要な指標、最近のイベントをまとめて確認できるダッシュボードです。

さまざまな企業や組織で使える画面を目指し、特定の会社や業界に依存しないデザインにしました。画面内の数値とイベントは動作確認用のサンプルデータです。実際のサービスや外部APIには接続していません。

## ✨ 主な機能

| 機能 | 内容 |
| --- | --- |
| 📊 主要指標 | 処理件数、平均処理時間、稼働サービス数を表示 |
| 🔔 イベント一覧 | 運用中に発生するイベントをリアルタイムで表示 |
| ⚡ クイックアクション | 操作内容を作業履歴に追加 |
| 🕒 日時表示 | 現在の日付と時刻を自動更新 |
| 📱 レスポンシブ対応 | PC・タブレット・スマートフォンで見やすく表示 |
| ⌨️ 操作性への配慮 | セマンティックHTMLとキーボードフォーカスに対応 |

## 🖥️ 使用技術

`HTML5`　`CSS3`　`JavaScript (ES6+)`　`GitHub Pages`

- CSS Grid・Flexboxを使ったレイアウト
- JavaScriptによるイベント表示と操作履歴の追加
- ライブラリやフレームワークに依存しない構成

## 🚀 はじめかた

### ブラウザで開く

`index.html`をブラウザで開くだけで利用できます。パッケージのインストールは不要です。

### ローカルサーバーで開く

リポジトリのルートで次のコマンドを実行し、`http://localhost:8000`にアクセスしてください。

```bash
python -m http.server 8000
```
