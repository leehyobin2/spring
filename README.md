# SENTINEL 監視ダッシュボード

さまざまな企業や組織で活用できる、運用状況をひと目で確認するための監視ダッシュボードです。特定の企業や業界に限定せず、主要指標、サービス状況、最近のアクティビティを確認できる汎用的な画面として制作しました。

## デモ

GitHub Pages: [https://leehyobin2.github.io/spring/](https://leehyobin2.github.io/spring/)

## 主な機能

- リクエスト数、平均処理時間、サービス稼働状況などの主要指標を表示
- 最近のイベントをリアルタイムで表示
- クイックアクションから作業履歴を追加
- 画面サイズに応じてレイアウトが変わるレスポンシブデザイン
- 日付と時刻を自動表示
- セマンティックHTMLとキーボード操作に配慮したフォーカス表示

画面内の数値やイベントはUIの動作を示すサンプルデータであり、実際のサービスや外部APIには接続していません。

## 使用技術

- HTML5
- CSS3（Grid、Flexbox、メディアクエリ）
- JavaScript（ES6+）
- GitHub Pages

## ローカルでの実行方法

追加のパッケージは不要です。`index.html`をブラウザで開いてください。ローカルサーバーを使う場合は、リポジトリのルートで次のコマンドを実行します。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

## ポートフォリオについて

SENTINELはポートフォリオ用のプロジェクト名です。セマンティックHTMLによる構造設計、CSS GridとFlexboxを使ったレスポンシブレイアウト、JavaScriptによる時計・イベント表示・作業履歴の実装に取り組みました。フレームワークを使わず、ブラウザ標準の技術で単一ページのインターフェースを制作しています。
